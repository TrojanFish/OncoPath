普通产品追求：

* 快；
* 多功能；
* 高转化。

医疗产品追求：

* 安心；
* 清晰；
* 不制造误解；
* 信息层级合理。

LungEvidence 的前端核心不是“展示数据”，而是：

> 把复杂医学证据转换成患者能理解的信息路径。
