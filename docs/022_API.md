# API Specifications

## 1. 概述 (Overview)
The backend exposes a RESTful API built with FastAPI. It handles data ingestion, querying, and the orchestration of AI agents. All endpoints return JSON.

## 2. API Endpoints

### 2.1. 患者交互接口 (Patient Interaction APIs)

#### `POST /api/v1/profile`
- **Description:** Submit a patient's pathological profile.
- **Request Body:**
  ```json
  {
    "age": 60,
    "gender": "male",
    "histology": "adenocarcinoma",
    "factors": ["STAS", "Micropapillary > 5%"],
    "stage": "IB"
  }
  ```
- **Response:** Returns a `profile_id` (UUID).

#### `GET /api/v1/evidence-report/{profile_id}`
- **Description:** Generate and retrieve the personalized evidence report based on the submitted profile.
- **Response:**
  ```json
  {
    "summary": "...",
    "matched_factors": [
      {
        "factor_name": "STAS",
        "evidence_summary": "...",
        "related_studies": [
          {"pmid": "123456", "level": 4}
        ]
      }
    ]
  }
  ```

### 2.2. 知识库查询接口 (Knowledge Base APIs)

#### `GET /api/v1/studies`
- **Description:** Search for studies. Supports filtering and pagination.
- **Query Params:** `?factor=STAS&min_level=4&limit=20`
- **Response:** List of study objects.

#### `GET /api/v1/factors/{id}`
- **Description:** Retrieve details of a specific medical factor, including its description and graph connections.
- **Response:** Factor details, synonyms, and related factors.

### 2.3. 系统管理与处理接口 (Admin & Processing APIs)

#### `POST /api/v1/parse-report`
- **Description:** Upload an unstructured medical report (text or image/PDF via OCR) for AI extraction.
- **Request:** Multipart form data (file) or raw text.
- **Response:**
  ```json
  {
    "extracted_profile": {
      "histology": "adenocarcinoma",
      "factors": ["LVI", "STAS"],
      "confidence_scores": {"STAS": 0.95}
    }
  }
  ```

#### `POST /api/v1/admin/trigger-sync`
- **Description:** Manually trigger the daily PubMed pipeline sync.
- **Auth:** Requires Admin API Key.
- **Response:** Status of the background job.
